
# SysPulse - Device Telemetry Monitoring Platform

SysPulse is a React-based device monitoring dashboard.

## Features

- User login and registration
- User dashboard
- Admin dashboard
- Device monitoring
- Telemetry charts
- Add device interface
- Simulated device data

## Technologies Used

- React
- JavaScript
- Vite
- Tailwind CSS
- Lucide React

## Installation

First, install Node.js.

Open the project folder in VS Code and open the terminal.

Run:

```bash
npm install
```

## Run the Project

Run:

```bash
npm run dev
```

Open the local URL displayed in the terminal.

## Build the Project

Run:

```bash
npm run build
```

## Note

This project currently uses simulated frontend data.

A backend and real device connection need to be implemented separately.
